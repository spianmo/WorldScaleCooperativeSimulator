# 纹理资源

该目录用于放置道路、建筑、草地、混凝土、沥青、雨雪雾等物理世界材质纹理。

当前已包含：

- `asphalt_01_diff_1k.jpg`：来自 Poly Haven 的 CC0 沥青路面纹理。
- `facade001_glass_color_1k.jpg`：来自 ambientCG 的 CC0 现代玻璃幕墙 1K 颜色贴图，当前用于城市大楼外立面。
- `rectangular_facade_tiles_diff_1k.jpg`：来自 Poly Haven 的 CC0 现代矩形立面瓷砖 1K 漫反射纹理，作为建筑立面备选资源留档。
- `rectangular_facade_tiles_ao_1k.jpg`：来自 Poly Haven 的 CC0 现代矩形立面瓷砖 1K AO 贴图，随备选立面资源留档，当前未接入运行时材质。
- `concrete_polyhaven_1k.jpg`：来自 Poly Haven 的 CC0 混凝土 1K 漫反射纹理，当前用于铺装表面和混凝土 fallback。
- `grass_rock_polyhaven_1k.jpg`：来自 Poly Haven 的 CC0 草地/岩石 1K 漫反射纹理，当前用于地形和开放空间。
- `grass_procedural_1k.png`：本地生成草地纹理，作为 fallback 留档。
- `concrete_procedural_1k.png`：本地生成混凝土纹理，作为 fallback 留档。

资产来源、许可证和用途记录在 `manifest.json`。
